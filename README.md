# sahina/homebrew-tap

Homebrew formulae for two unrelated projects.

```bash
brew tap sahina/tap
```

| Formula | Project | Install |
| --- | --- | --- |
| `ironflow` | [Ironflow](https://ironflow.run) — durable runtime for AI agents and event-driven systems | `brew install sahina/tap/ironflow` |
| `cvt` | [cvt](https://github.com/sahina/cvt) — contract validation for OpenAPI specs | `brew install sahina/tap/cvt` |

Formulae are generated by GoReleaser at each release. Do not edit them by hand;
changes are overwritten on the next publish.

## Bugs

Tap problems — a broken formula, a bad checksum, `brew tap` failing — belong
[here](https://github.com/sahina/homebrew-tap/issues).

Bugs in the software itself go to the project:

- **Ironflow** → [sahina/ironflow-issues](https://github.com/sahina/ironflow-issues/issues/new/choose)
- **cvt** → [sahina/cvt/issues](https://github.com/sahina/cvt/issues)

For Ironflow security disclosures use a
[private advisory](https://github.com/sahina/ironflow-issues/security/advisories/new),
never a public issue.
